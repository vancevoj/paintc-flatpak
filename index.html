paint.c

A fast, native image editor with layers, effects and adjustments.

Install on Linux

Install with Flatpak

Open the downloaded file with GNOME Software or KDE Discover. paint.c then updates together with your other apps. Or use a terminal:

flatpak install --user https://vancevoj.github.io/paintc-flatpak/io.github.vancevoj.paintc.flatpakref

To add the repository only (paint.c then shows up in your software center):

flatpak remote-add --user --if-not-exists paintc https://vancevoj.github.io/paintc-flatpak/paintc.flatpakrepo

Other downloads

AppImage, Windows installer and portable zip, and the source code are on the releases page. Optional plugins are listed in the project README.
